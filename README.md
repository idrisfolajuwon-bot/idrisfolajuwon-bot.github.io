# IDRIS AI STUDIO

**An independent AI workspace developed under I D LABS.**

IDRIS AI STUDIO brings an AI chat assistant and creative tools together in one online workspace.

## Features
- AI chat
- Voice conversations in compatible browsers
- Image creation and image understanding
- Text extraction from supported PDF and Word DOCX documents
- Prompt Lab
- Creation Vault
- Research Desk
- Studio Guide
- Video Lab for storyboarding and planning (not video rendering)

Some features depend on internet access, browser support and connected service availability.

## Independence
IDRIS AI STUDIO is a separate independent project developed under I D LABS. It is not ChatGPT, not an OpenAI product, and is not affiliated with or endorsed by OpenAI or other AI providers.
