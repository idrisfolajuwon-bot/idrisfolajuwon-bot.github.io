03 / SECURITY

What has been reviewed?

We review application code and access rules as products change. A previous review of IDRIS AI STUDIO found user-scoped database access policies for saved conversations and memories. A review of CHATDUN found row-level security enabled on the 14 database tables inspected, with message access scoped to conversation membership and restrictions on voice-note storage.

These were code and configuration reviews, not an independent penetration test, formal security certification or guarantee that every account, device and session scenario is free of defects. We will not describe a product as “100% secure”.

04 / PRIVACY

Use products thoughtfully

  • Read the privacy information shown inside each product before using it.
  • Do not share passwords, one-time verification codes, bank details or highly sensitive documents in chats or AI prompts.
  • Only share content you have permission to upload or send.
  • CHATDUN's in-app Privacy & Safety notice is available from the profile/account area.
  • CHATDUN account deletion requests are reviewed manually; submitting a request does not mean deletion has already happened.

This Trust Centre is a plain-language product transparency page. It is not a substitute for a complete, jurisdiction-specific privacy policy or legal advice.
